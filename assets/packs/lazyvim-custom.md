# Custom LazyVim keymaps

<!-- keymaps:start -->
## Marks

| Key | Description | Mode |
| --- | --- | --- |
| <code>ma</code> | Set buffer-local mark a | **n** |
| <code>mA</code> | Set a global (cross-file) mark A | **n** |
| <code>`a</code> | Jump to local mark a | **n** |
| <code>`A</code> | Jump to global mark A | **n** |
| <code>[`</code> | Previous lowercase mark in buffer | **n** |
| <code>]`</code> | Next lowercase mark in buffer | **n** |

<!-- keymaps:end -->
